# Anaira Hotel Booking Connector

WordPress/Elementor connector for the Anaira Supabase Booking Engine.

## Setup
1. Install and activate the plugin.
2. WordPress Admin → Settings → Anaira Booking.
3. Add the Anaira Supabase URL, publishable key and the property's `restaurants.slug`.
4. Add `[anaira_booking]` to an Elementor Shortcode widget or WordPress page.

WordPress remains the website/connector layer. Anaira Supabase remains the canonical booking engine.
