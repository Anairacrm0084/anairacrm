# Anaira SEO + AI Review System

## SEO plugin
- Site/domain registry
- Page-level technical/on-page score
- Title/meta/H1/canonical/schema checks
- Keyword clusters and target URLs
- Search Console/GA4 integration slots
- Search performance metrics
- Redirect management
- Internal-link suggestions
- AI content jobs with approval before publishing
- Sitemap/robots configuration

## AI Review plugin
- Review source/location registry
- Review ingestion model
- Rating + sentiment + topic classification
- AI reply draft generation
- Human approval workflow
- Review request queue
- WhatsApp/SMS/email/in-app request channels
- Service-recovery actions for negative feedback
- Reputation metrics
- Automation rules

## Automation
Booking/stay/dining completion can enqueue review requests. The system should invite customers consistently rather than selectively soliciting only positive reviewers. AI-generated public replies remain approval-gated by default.

## Not falsely claimed
Live provider credentials, Google Business Profile API access, Search Console API access, GA4 credentials, WhatsApp/SMS/email provider delivery, and external review ingestion must be connected and verified before production certification.
