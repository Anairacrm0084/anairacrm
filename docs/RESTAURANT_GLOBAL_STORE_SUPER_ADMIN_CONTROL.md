# Restaurant Global Store — Super Admin Control

The `/store` Restaurant Marketplace is the global platform-owned storefront.

## Ownership
- Super Admin: global marketplace branding, hero, banners, layout, section visibility, marketplace rules, SEO and footer.
- Business Admin: only their own restaurant/hotel store presentation and business settings.
- Restaurant SaaS: operational menu, prices, variants, add-ons, availability and orders remain canonical.

## Global controls
- Hero desktop/mobile imagery
- Hero CTA
- Theme preset
- Primary/accent/background/surface/text colours
- Container width
- Restaurant/dish/banner grid density
- Card radius
- Search/mode/offers/restaurants/popular/footer visibility
- Promotional banners
- Marketplace approval/commission/payment policy
- SEO title/description
- Footer text

## Preview
Use `/store` from the Super Admin control page to preview the global store.
