# Multi-Type Restaurant Admin Visibility Fix — 2026-09-29

Business Admin navigation now keeps a dedicated RESTAURANT MANAGEMENT group visible alongside the selected hospitality management groups.

Restored controls:
- Restaurant Setup — `/restaurant-setup`
- My Restaurant Store — `/store-builder?kind=restaurant`
- Anaira POS / Menu — `/pos`
- Restaurant Reservations — `/reservation`
- Food Delivery — `/delivery`

The hospitality-specific Hotel/Camping/Homestay/Guest House/Cottage navigation remains unchanged. This prevents multi-type hospitality sidebar generation from hiding the restaurant administration workflow.
